## Overview

MAMION TECH is an intercity carpooling platform designed to simplify travel across Cameroon by connecting passengers with drivers and transportation providers.

The platform aims to digitalize the intercity transportation booking process, allowing users to explore available destinations, compare fares, select drivers and reserve seats in advance.

The project was developed in 2023 as part of an academic internship at Mamion Tech.

## Problem Statement

Intercity transportation in Cameroon often involves manual booking processes, long waiting times and limited access to reliable travel information.

MAMION TECH was designed to address these challenges through a centralized web and mobile platform.

## Project Objectives

* Facilitate intercity travel reservations.
* Connect passengers with drivers and transportation agencies.
* Provide access to available routes, schedules and fares.
* Improve travel information and driver identification.
* Support journey tracking and location services.
* Provide a centralized platform for managing transportation activities.

## Software Architecture

The solution was designed around a multi-tier architecture separating:

1. **Presentation Layer:** Web and mobile user interfaces.
2. **Application Layer:** Backend services and API endpoints.
3. **Data Layer:** Database management and persistence.

The backend follows the Model-View-Controller (MVC) architectural pattern.
